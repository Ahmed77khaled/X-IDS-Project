==============================================================================
   🎓 دليل التشغيل السريع لمشروع التخرج X-IDS (لأعضاء فريق العمل)
==============================================================================

📌 المتطلبات الأساسية فقط (مرة واحدة على جهازك):
 1. بايثون (Python 3.8+): من الرابط https://www.python.org/downloads/
    (مهم جداً: علم صح على Add Python to PATH أثناء التثبيت).
 2. برنامج VS Code: من الرابط https://code.visualstudio.com/

------------------------------------------------------------------------------
🚀 خطوة التشغيل الوحيدة:
------------------------------------------------------------------------------
 اضغط مرتين (Double Click) على ملف:
 👉 [ تشغيل_المشروع.bat ]

 السكريبت مبرمج بالكامل للقيام بالآتي أوتوماتيكياً:
 1. فحص بايثون على جهازك والتأكد من إضافته للمسار.
 2. إنشاء بيئة عمل افتراضية معزولة (.venv).
 3. تسطيب جميع مكتبات الذكاء الاصطناعي (Pandas, Scikit-Learn, XGBoost, SHAP).
 4. تسجيل كيرنل خاص بالمشروع في VS Code.
 5. فحص وجود ملف الداتاسيت وتنبيهك بمكانه.
 6. فتح النوت بوك my_model_training.ipynb تلقائياً في VS Code.

------------------------------------------------------------------------------
🎯 ماذا تفعل بمجرد فتح VS Code؟
------------------------------------------------------------------------------
 1. من أعلى الشاشة على اليمين، اضغط على زر: [ Select Kernel ]
 2. اختر من القائمة: [ Python Environments... ]
 3. اختر الكيرنل المسجل: [ Python (X-IDS Machine Learning) ] أو (.venv)
 4. اضغط على أيقونة تشغيل الصوت 🎙️ في كل خطوة للاستماع لشرح "فِلحو"
    ثم اكتب الكود واضغط (Shift + Enter).
